поведение шапки, фильтров, футера, формы и экрана входа в админку.

## 5. Доступность

* Lighthouse Accessibility — **100** на всех шести замерах.
* Клавиатурный проход выполнен вручную и частично автоматизирован:
  * Tab с начала страницы → skip-link, Enter → переход к содержимому;
  * фильтры кейсов проходятся Tab и активируются Enter;
  * мобильное меню запирает фокус, закрывается Escape, возвращает фокус;
  * все поля формы достижимы, ошибки связаны через `aria-describedby`;
  * видимый фокус (`:focus-visible`) присутствует на тёмном и светлом фоне.
* `prefers-reduced-motion`: анимации отключены, контент виден сразу, сцена
  рендерит один статичный кадр (проверено E2E и отдельным контекстом браузера).
* Canvas помечен `aria-hidden` и `role="presentation"`; вся информация первого
  экрана продублирована обычным HTML.

| # | Дефект | Как обнаружен | Исправление |
| --- | --- | --- | --- |
| 1 | Изображения не проходили оптимизацию: 403 от `/_next/image` | Скриншот-прогон (403 в консоли) | `toImageSrc` приводит URL медиа к относительному пути; Next 16 блокирует загрузку с приватных IP |
| 2 | CLS 0.33 на `/cases` | Lighthouse | Фильтрация переведена на сервер; побочно — работа без JS |
| 3 | Контраст приглушённого текста 4.1:1 | Lighthouse | Токены `--gm-steel` и `--fg-subtle` пересчитаны |
| 4 | Пропуск уровня заголовков (`h1` → `h3`) | Lighthouse | Настраиваемый уровень заголовка карточки; надзаголовок секции стал `h2` |
| 5 | LCP 5.6 с / TBT 990 мс на мобильной главной | Lighthouse | Постер вынесен в серверный рендер с `priority`; сцена стартует после `load`; на слабых touch-устройствах не запускается |
| 6 | `robots.txt` не собирался | Ручная проверка маршрутов | Файл перенесён из route group в корень `app/` |
| 7 | Ссылка карточки имела `aria-label`, не совпадающий с видимым текстом | Lighthouse (`label-content-name-mismatch`) | `aria-label` убран |
| 8 | Автосохранение убирало кнопку «Сохранить черновик» | E2E-прогон админки | Автосохранение выключено, оставлен явный контроль |

## 7. Проверено вручную

* Вход в админку, создание/публикация/снятие с публикации кейса.
* Загрузка изображения и обязательность alt.
* Предпросмотр черновика и выход из него.
* Отправка заявки и её появление в разделе «Заявки».
* Поведение сайта при отключённом JavaScript (главная, кейсы, фильтры).
* Отсутствие 3D-сцены при отсутствии WebGL (подмена `getContext`).

## 8. Что не проверялось

| Область | Причина |
| --- | --- |
| Реальные GPU | Среда использует программный рендерер SwiftShader. Поведение сцены на настоящем GPU не измерено |
| Safari и Firefox | В среде доступен только Chromium. Использованы стандартные API; кроссбраузерная проверка нужна перед запуском |
| Реальные скринридеры (NVDA/VoiceOver) | Недоступны. Проверена только семантика и автоматические аудиты |
| Отправка писем | SMTP не предоставлен. Путь сохранения заявки в БД проверен полностью |
| S3-хранилище | Проверена конфигурация подключения, но не реальный бакет |
| Нагрузка | Нагрузочное тестирование не проводилось |

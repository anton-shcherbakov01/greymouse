# Дизайн-система «Серая Мышь»

Все значения живут в `src/styles/tokens.css` и подключаются к Tailwind через
`@theme inline` в `src/styles/globals.css`. Один источник правды: и утилиты, и
обычный CSS, и WebGL-сцена читают одни и те же переменные.

## 1. Идея

**Серый мир, в котором есть один сигнал.**

Незаметность в названии студии — это метод работы, а не недостаток. Визуально:
почти вся палитра — графит и холодные серые, и ровно один цвет отмечает то, что
действительно важно: активное состояние, результат, действие.

## 2. Цвет

### Базовые токены

| Токен | Значение | Роль |
| --- | --- | --- |
| `--gm-ink` | `#0b0c0e` | Фон тёмных секций |
| `--gm-graphite` | `#16181c` | Поверхности на тёмном |
| `--gm-slate` | `#2a2e35` | Границы на тёмном |
| `--gm-steel` | `#868d99` | Приглушённый текст на тёмном |
| `--gm-silver` | `#a8adb7` | Вторичный текст на тёмном |
| `--gm-mist` | `#d9dbe0` | Границы на светлом |
| `--gm-paper` | `#f4f4f2` | Фон светлых секций |
| `--gm-signal` | `#c9f24a` | **Единственный акцент** |
| `--gm-signal-dim` | `#a6c93c` | Акцент на светлом фоне |
| `--gm-danger` | `#ff6b52` | Ошибки форм |

### Правило акцента

Сигнальный лайм используется **только** так:

1. как заливка с тёмным текстом поверх (кнопка, активная «пилюля»);
2. как текст — **исключительно** на тёмном фоне;
3. как тонкая линия, подчёркивание или маркер.

Причина: `#c9f24a` на `#f4f4f2` даёт контраст ~1.5:1 — как мелкий текст на светлом
он нечитаем. На светлых секциях роль `--accent` переключается на `--gm-signal-dim`,
и он всё равно применяется только заливкой и линиями.

### Переключение схем

Семантические роли (`--bg`, `--fg`, `--fg-muted`, `--fg-subtle`, `--border`,
`--accent`, `--accent-fg`) переопределяются классами `.gm-dark` и `.gm-light` на
секции. Благодаря этому один и тот же компонент работает на тёмном и светлом
фоне без вариантов пропсов.

### Проверенный контраст

Замерено Lighthouse (категория accessibility = 100 на всех страницах):

| Пара | Контраст | Статус |
| --- | --- | --- |
| `--gm-silver` на `--gm-ink` | 9.9:1 | AA/AAA |
| `--gm-steel` на `--gm-ink` | 5.6:1 | AA |
| `--fg-subtle` (`#5f6672`) на `--gm-paper` | 5.4:1 | AA |
| `--gm-ink` на `--gm-signal` | 15.6:1 | AAA |

Первая версия `--gm-steel` (`#6b7280`) давала 4.1:1 и не проходила AA — это было
найдено автоматической проверкой и исправлено.

## 3. Типографика

| Роль | Шрифт | Где применяется |
| --- | --- | --- |
| Display | **Onest** (400/500/600) | Заголовки всех уровней |
| Body | **Inter** (400/500/600) | Основной текст, интерфейс |
| Mono | **JetBrains Mono** (400/500) | Надзаголовки, годы, теги, метрики |

Все три поддерживают кириллицу и подключены через `next/font/google` — Next
скачивает файлы во время сборки и раздаёт со своего домена. Внешних запросов к
Google в рантайме нет. `display: swap` и метрики фоллбэка исключают сдвиг вёрстки
(CLS = 0 на всех измеренных страницах).

### Шкала

Размеры заданы через `clamp()` — промежуточных брейкпоинтов для типографики нет.

| Токен | Диапазон | Трекинг |
| --- | --- | --- |
| `--text-hero` | 3 → 8.5 rem | `-0.035em` |
| `--text-4xl` | 2.75 → 6 rem | `-0.025em` |
| `--text-3xl` | 2.25 → 4 rem | `-0.025em` |
| `--text-2xl` | 1.75 → 2.75 rem | `-0.015em` |
| `--text-xl` | 1.375 → 1.75 rem | `-0.015em` |
| `--text-base` | 1 rem | normal |
| `--text-meta` | 0.75 rem | `+0.08em`, uppercase |

Отрицательный трекинг на крупных размерах — подтверждённый паттерн из
исследования (bravoure −0.02em, yummygum −0.04em, gravity −0.025em).

**Правило для кириллицы:** капслок применяется только к `--text-meta`.
Русские слова длиннее латинских, и капслок в крупных заголовках ухудшает
читаемость — поэтому в заголовках его нет.

## 4. Сетка и ритм

* `--container-max: 90rem` (1440 px), `--container-text: 44rem`.
* `--gutter: clamp(1.25rem, 4vw, 4.5rem)` — единые боковые поля.
* 12-колоночная сетка (`md:grid-cols-12`) для асимметричных раскладок.
* Вертикальный ритм: `--space-section` (4.5→10 rem), `--space-block` (2.5→5 rem),
  `--space-stack` (1→1.75 rem).
* Скругления минимальны: `--radius-md: 4px` для интерактивных элементов,
  `--radius-pill` для «пилюль». Секции — прямоугольные.

**Композиционный приём:** «огромное слово слева + узкая колонка текста справа»
(взято из разбора страницы услуг lightbase). Применён на `/cases`, `/services`,
главной.

## 5. Motion

### Токены

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--dur-quick` | 160 ms | Hover, фокус, мелкие интерактивы |
| `--dur-base` | 320 ms | Смена состояний, меню |
| `--dur-slow` | 640 ms | Крупные переходы, сигнальная линия |
| `--dur-reveal` | 720 ms | Появление блока при скролле |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | Появление |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | Двусторонние переходы |
| `--ease-spring` | `linear(...)` из 13 точек | Пружина средствами CSS |
| `--stagger` | 60 ms | Шаг задержки в группе |
| `--reveal-distance` | 18 px | Смещение при появлении |

Пружинная кривая через CSS-функцию `linear()` — приём, снятый с gravity.nl.

### Инструменты

* **CSS + `IntersectionObserver`** — основной механизм появления (`Reveal`).
  Наблюдатель один раз ставит `data-revealed="true"`, дальше работает CSS-переход.
  Пофреймовой JS-анимации нет.
* **Motion (`motion@12`)** — только там, где CSS не справляется: мобильное меню
  (`AnimatePresence` с возвратом фокуса).
* Смена выдачи фильтров анимируется **чистым CSS** через `key` на списке.

### Брендовый приём — *signal sweep*

При появлении блока по его верхней границе один раз проходит тонкая сигнальная
линия, после чего проступает текст (`.gm-signal-sweep`). Один приём,
применяемый последовательно, вместо анимации всего подряд.

### Что не делаем

Анимация каждого текста, постоянное движение, magnetic cursor, scroll hijacking,
smooth-scroll-движки, подмена курсора на touch.

### `prefers-reduced-motion`

* Все `animation-duration` и `transition-duration` → `0.01ms`.
* `[data-reveal]` сразу видимы: `IntersectionObserver` не создаётся вовсе.
* Сигнальная линия и появление карточек отключены.
* 3D-сцена рендерит **один статичный кадр** и останавливается.

## 7. Доступность как часть системы

* Видимый фокус (`:focus-visible`) — сигнальный контур 2 px с отступом 3 px,
  одинаковый на тёмном и светлом.
* Skip-link — первый элемент в табуляции.
* Мобильное меню — `role="dialog"` с ловушкой фокуса, Escape и возвратом фокуса.
* Фильтры — ссылки с `aria-current`, доступны с клавиатуры и без JS.
* Иерархия заголовков без пропусков: ровно один `h1` на страницу.
* Canvas сцены — `aria-hidden` + `role="presentation"`.

## 8. Знак студии

Два контура-«уха», овал-силуэт и сигнальная черта внутри. Намёк на мышь без
буквального маскота, тот же принцип, что и в 3D-сцене. Файл:
`src/components/brand/Wordmark.tsx`, производные — `public/favicon.svg`,
`public/icon.svg`, `public/apple-icon.png`, генерируются
`scripts/render-brand-assets.mjs`.
